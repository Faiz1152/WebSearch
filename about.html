About WebSearch

What is WebSearch?

WebSearch is a clean, modern search interface designed to provide a professional and intuitive search experience. It offers a simple, distraction-free way to search the web with support for multiple search types including web results, images, news, and videos.

How It Works

WebSearch operates as a frontend interface that communicates with a backend service. When you search, WebSearch sends your query to /api/search, where the backend processes your request and retrieves results from configured search providers.

The backend is responsible for:

  • Processing search queries
  • Managing provider integrations
  • Retrieving and formatting results
  • Handling API credentials securely

Search Providers

WebSearch is designed to work with multiple search providers through its backend service. The backend determines which provider handles your search and retrieves the results. WebSearch does not directly connect to any search service—all provider integrations are managed by the backend for security and privacy.

Privacy & Design

WebSearch is built with simplicity and user experience in mind. It provides:

  • A clean, minimal interface
  • Support for light and dark themes
  • Customizable search behavior
  • No account or tracking requirements
  • Proper separation between frontend and backend

Architecture

WebSearch follows a clean separation of concerns:

  • Frontend: HTML, CSS, and JavaScript—handles user interface and search presentation
  • Backend: Manages API credentials, provider integrations, and result delivery
  • Search Providers: Third-party services integrated through the backend

WebSearch is designed to be a continuously maintained search service that works with any compatible search provider backend.
